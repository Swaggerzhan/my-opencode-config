# my-opencode-config

个人 OpenCode 配置,以插件形式分发:agents、slash 命令、`sbash` 工具、
MCP 服务器、权限底线、全局指令、agent 模型映射、TUI 侧边栏。

要求:OpenCode V2(`opencode --version` ≥ 2.0)。

## 安装

### 方式一:插件命令安装(推荐)

直接指定 GitHub 仓库,一条命令完成:

```bash
opencode plugin add github:Swaggerzhan/my-opencode-config
opencode service restart
```

该命令会把插件写进全局配置 `~/.config/opencode/opencode.jsonc` 的
`plugins`,并安装到插件缓存。

- 跟踪分支:`github:Swaggerzhan/my-opencode-config#main`
- 钉版本:`github:Swaggerzhan/my-opencode-config#v0.1.0`
- 私有仓库:`opencode plugin add git+ssh://git@github.com/Swaggerzhan/my-opencode-config.git`

### 方式二:手动 clone 安装

适合想先审阅或改动再用的场景:

```bash
git clone https://github.com/Swaggerzhan/my-opencode-config.git
cd my-opencode-config
npm install   # 必须执行:本地路径加载不会自动安装依赖
```

然后把仓库的绝对路径加进全局配置 `~/.config/opencode/opencode.jsonc`:

```jsonc
{
  "plugins": ["/absolute/path/to/my-opencode-config"]
}
```

重启 OpenCode 生效。此方式下改动本地文件后重载即可,无需重新安装。

## 可选配置

以下两份文件与插件相互独立,**均为可选**,按需取用。

### opencode.jsonc(provider / 模型 / 权限)

provider 和 model 定义不走插件,由用户自己的全局配置负责。仓库附带一份现成的
[`opencode.jsonc`](opencode.jsonc):四个环境变量驱动的 provider、默认模型、
默认 agent、全局权限规则和 compaction 预留。可直接作为全局配置,或按需把其中的
段落合并进已有配置:

```bash
curl -o ~/.config/opencode/opencode.jsonc \
  https://raw.githubusercontent.com/Swaggerzhan/my-opencode-config/main/opencode.jsonc
```

该文件通过 `{env:...}` 读取下列变量,缺哪组哪个 provider 不可用:

| 变量 | 用途 |
|---|---|
| `OPENCODE_OPENAI_ENDPOINT` / `OPENCODE_OPENAI_KEY` | OpenAI(gpt-5.6-sol/terra/luna),默认模型 |
| `OPENCODE_DEEPSEEK_ENDPOINT` / `OPENCODE_DEEPSEEK_KEY` | DeepSeek(v4-pro/flash),兼 title 生成 |
| `OPENCODE_KIMI_ENDPOINT` / `OPENCODE_KIMI_KEY` | Kimi(kimi-k3),各 agent 的默认模型 |
| `OPENCODE_XAI_ENDPOINT` / `OPENCODE_XAI_KEY` | xAI(grok-4.5) |
| `TAVILY_API_KEY` | tavily 远程 MCP(此项由插件自身读取,与上表文件无关) |

`dep_search` MCP 额外要求 `codebase-memory-mcp` 在 PATH 上,安装与索引方法见
[docs/codebase-memory-mcp.md](docs/codebase-memory-mcp.md)。

### cli.json(TUI 键位)

`cli.json` 是终端客户端私有配置,插件无法注入。需要本仓库的 TUI 键位与
subagent-magazine 插件时,把 [`cli.json`](cli.json) 的内容手动合并进
`~/.config/opencode/cli.json`。

## 更新

```bash
opencode plugin check      # 检查有无更新
opencode plugin update github:Swaggerzhan/my-opencode-config
opencode service restart
```

未 pin tag/commit 时跟踪默认分支;pin 住的版本不会被 update 动。
手动 clone 安装的,直接 `git pull` 后重启即可。

注意:update/remove 的参数必须是 `plugins` 里的完整条目字符串
(如 `github:Swaggerzhan/my-opencode-config`),不能用
`opencode plugin list` 显示的短 ID,否则报 "Plugin is not configured"。

## 卸载

```bash
opencode plugin remove github:Swaggerzhan/my-opencode-config
opencode service restart
```

插件卸载时自动清理它生成的 agent 文件(`~/.config/opencode/agents/` 中带
`# generated by my-opencode-config` 标记的文件)。手动 clone 安装的,把配置里的
路径条目删掉即可。

## agent 模型映射

每个 agent 用哪个模型,由插件读取
[`my-opencode-config.jsonc`](my-opencode-config.jsonc) 决定,格式为
`"<agent-id>": "<provider>/<model>[#variant]"`。

不改插件的覆盖方法:把该文件拷到 `~/.config/opencode/my-opencode-config.jsonc`
再编辑;用户文件里的条目按 agent 覆盖内置默认,未提到的 agent 沿用仓库默认。
文件有 watcher,保存即生效。

## 内容清单

### 主 agent

- **main**(默认):通用主力,持有全部工具。
- **codeleader**:牵头设计与代码实现,可派发 coder / codebuilder 子任务。
- **insight**:调研,可查依赖图谱(dep_search_*)和网络(tavily),可派发 scout。

### 子 agent

- **coder**:架构理解、设计文档与代码实现(mode 为 all,也可作主 agent)。
- **codebuilder**:跑构建、测试与代码生成(protoc、go build、go test、gofmt 等)。
- **general**:通用多步研究与执行。
- **scout**:只读侦察,搜索代码库与网络。

内置的 build / plan / explore 被移除,内置 general 由同名自定义 agent 接管。

### 工具

- **sbash**:白名单命令工具(git / openspec / ls / rm / rmdir,execFile 直接执行,
  不经过 shell)。codeleader / coder / insight 的命令执行只走 sbash。

### TUI 侧边栏

侧边栏内容替换为三个区块(随插件自动加载,无需额外配置):

- **Context Usage**:上下文用量进度条(宽度与标题同宽),显示当前已用 / 上限
  (K)与百分比;100K 以下绿色,100K–180K 黄色,180K 起红色。
- **MCP**:各 MCP server 的连接状态。
- **Tools**:当前 session 的 agent 实际可见的工具列表(含 sbash),点击标题或
  命令面板 "Toggle sidebar tools" 展开 / 收起。

## 插件选项

把全局配置 `plugins` 里的字符串条目改成对象形式即可逐项关闭:

```jsonc
{
  "plugins": [
    {
      "package": "github:Swaggerzhan/my-opencode-config",
      "options": {
        "agents": true,       // agent 文件物化 + 模型映射 + 内置 agent 裁剪 + 默认 agent
        "instructions": true, // AGENTS_.md 注入
        "commands": true,     // /dig /fixme
        "tools": true,        // sbash + shell 剔除
        "mcp": { "depSearch": true, "tavily": true }
      }
    }
  ]
}
```
